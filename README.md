# 目隠し将棋

盤を見ずに、声で指す将棋のウェブアプリです。

- **エンジン**：やねうら王（WebAssembly版）＋ 評価関数「つようら王11micro」
- **音声入力**：「ななろくふ」「同銀」「ごはちきん みぎ」「にさんふ なり」「ごごかく うつ」のように話すと、裏で盤に並べます
- **読み上げ**：相手の指し手を「ごて、さん よん ふ」のように読み上げます（王手も知らせます）
- **ヒント**：回数を決めておき、押すと盤面と持ち駒を数秒だけ表示します

## 使い方（ネットに置く：GitHub Pages の例）

1. GitHub で新しいリポジトリを作る（公開リポジトリ）
2. このフォルダの中身をすべてアップロードする（`index.html` がリポジトリの一番上に来るように）
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 1〜2分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く

初回は一度だけページが自動で再読み込みされます（エンジンのスレッドを有効にするため。`sw.js` がその役目です）。
スマホでもそのURLを開けば使えます。

## 使い方（自分のパソコンで試す）

```
python3 serve.py
```
を実行して、ブラウザで http://localhost:8000 を開きます。
`index.html` をダブルクリックで直接開くとエンジンが動きません（ブラウザの制限）。

## 対応ブラウザ

- 音声認識：Chrome / Edge（パソコン・Android）、Safari（iPhone・Mac）。Firefox は音声認識なし（文字入力は可）
- Chrome の音声認識はインターネット接続が必要です
- iPhone では自動の聞き取り開始が効かないことがあります。その場合は画面をタップしてから話してください

## 話し方のコツ

| 言いたい手 | 話し方の例 |
|---|---|
| ▲7六歩 | 「ななろくふ」「しちろくふ」 |
| 同銀 | 「どうぎん」「おなじくぎん」 |
| ▲5八金右 | 「ごはちきん みぎ」 |
| ▲2三歩成 | 「にさんふ なり」（「なり」を言わないと「成りますか？」と聞き返します） |
| ▲5五角打 | 「ごごかく うつ」 |

ほかに「ヒント」「もう一度（相手の手をもう一度読む）」「待った（2手戻す）」「投了」も声で言えます。
対局中のキー操作：スペース＝聞き取り開始、H＝ヒント、R＝もう一度。

## 強さについて

| 難易度 | 1手の探索 | 候補手からの選び方 |
|---|---|---|
| 初級（アマ1級くらい） | 60局面 | 上位6手から、最善手との差300点以内でばらつかせる |
| 中級（アマ初段くらい） | 300局面 | 上位4手から、差160点以内 |
| 上級（アマ2〜3段くらい） | 2,500局面 | 上位3手から、差70点以内 |

各段階の間は自己対局でおよそ R270〜300 の差があります。ただし「アマ○級／段」との対応は目安で、実際の人間との対局で確かめたものではありません。
強すぎ・弱すぎと感じたら、設定画面の「少し弱く／少し強く」を使うか、`levels.js` の数値を変えてください。

## ファイル構成

- `index.html` `style.css` `app.js` … 画面と対局の進行
- `shogi.js` … 将棋のルール（合法手）・棋譜表記・音声の解析
- `levels.js` … 難易度の設定
- `engine.js` `engine-worker.js` … エンジンとのやりとり
- `engine/` … やねうら王 WebAssembly 版
- `eval/` … 評価関数（つようら王11micro）
- `sw.js` … GitHub Pages でもエンジンを動かすための仕組み
- `serve.py` … 手元で試すためのサーバー
